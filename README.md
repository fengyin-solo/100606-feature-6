# 机场地面保障作业管理平台

面向航班保障、机位分配、廊桥靠接、摆渡车调度、行李装卸、航油加注、除冰作业与延误处置的一体化机场地面保障作业工作台。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `airport-ground-ops:entries` 这一项，或调用 `resetModule(模块)`。

## 航班保障占用校验

机位号与保障班组同一时段被两趟航班占用的「撞车」由占用台账统一兜底，代码在
`frontend/src/data/occupancy.ts`：

- **占用窗口**：计划到达前 30 分钟（进场）到计划到达后 90 分钟（离场），窗口相交即同一时段。
- **校验顺着列表筛选走**：航班页先按「计划到达、保障等级」筛出当天要接的任务，再逐条核冲突。
  冲突计数三条口径同源对账：`逐行冲突任务数 = 机位侧占用待办汇总 + 班组侧在岗冲突汇总 − 两处同撞`，
  页面上实时显示对账结果，不可能「筛出十条只报六条」。
- **两条证据的先后**：机位已被占用、班组同时段已有在岗任务两条证据同时成立时，**机位冲突先算、
  班组冲突紧随其后**（两条证据都保留并展示，不丢任何一条）。
- **回写停机位**：机位的「当前航班/占用时段/机位状态/占用待办」全部由台账投影，机位页读到的当前
  航班与航班页、班组页是同一份数据；待接收冲突挂为待办，已接收让位在待办中写明撞了哪班。
  维护中、已封闭的机位不参与占用回写。
- **状态不许跳步**：任务只能 `待接收 → 保障中 → 保障完成`，页面每行只亮出下一步动作，
  服务层也会再拦一次。
- **登记与接收**：登记时即核机位与班组，冲突只预警不拦截（预警写入机位占用待办）；接收时再核一遍，
  有冲突则拦截且任务留在「待接收」。
- **重复接收只算一次占用**：占用记录以航班任务 id 为唯一键，已在保障中的任务再次接收直接驳回，
  不会产生第二条占用。
- **存量回填让位次序**：首次打开（或示例数据版本升级）时，存量任务按计划到达回填占用记录；
  撞车时按 `计划到达早者先保位 → 同时到达按保障等级（要客 > 一级 > 二级 > 三级）→ 再按任务 id`
  让位，让位任务保留全部冲突证据并标为异常，待值班员改派机位或班组后即可正常接收。
- 纯逻辑行为测试在 `frontend/scripts/occupancy-test.mjs`，`cd frontend && npm test` 运行。
